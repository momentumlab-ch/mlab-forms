Anfrage- und Kontaktformulare für Kundenseiten von Momentum Lab.

== Description ==

Dies ist das Gerüst des Plugins. Es enthält bisher nur die Einstellungsseite mit dem Schalter für automatische Updates.

== Installation ==

1. Das ZIP `mlab-forms-<version>.zip` aus den GitHub-Releases herunterladen.
2. In WordPress unter «Plugins › Installieren › Plugin hochladen» das ZIP auswählen und installieren.
3. Plugin aktivieren.
4. Unter «Einstellungen › MomentumLab Forms» festlegen, ob Updates automatisch installiert werden (Standard: aus).
